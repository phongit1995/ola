# New board UI directions — layout and icon explorations

Created 2026-10-19 with the built-in imagegen tool as three new designs, without image references. These are visual concepts, not implemented gameplay screens.

User request: new UI styles and icon systems rather than recoloring the approved image. Retain scenic location tiles and central turn/dice/roll controls.

## 01 — Bold graphic

Top player row, dark navy UI, orange roll pad, bold geometric pictograms.

## 02 — Postcard paper

![Postcard paper](./board-ui-new-02-postcard-paper.png)

Stamp-shaped property cards, paper flag tokens, ledger scoreboard below the board, stamp-style icons and ticket action control.

## 03 — Urban atlas

![Urban atlas](./board-ui-new-03-urban-atlas.png)

Four inner-corner player panels, jade center with circular countdown, disc tokens, monoline wayfinding icons, dark jade action control.
