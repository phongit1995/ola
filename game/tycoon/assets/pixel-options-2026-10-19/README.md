## Pixel retro 8-bit

Authentic COARSE 8-BIT tile art. Each scenic tile has roughly a 16–24 by 20–28 logical-pixel picture enlarged with nearest-neighbor to show big 4–6 output-pixel square clusters. Tight palette of about 12–16 punchy colors, deep navy outlines one logical pixel thick, blocky tree canopies, angular mountain steps, geometric little clouds, bold cyan water. Recognizable icon-like travel landscapes, confident chunky silhouettes, two-tone shadows, no noise and no intricate texturing. A cheerful old-school adventure-map art direction. Truly large visible squares, do not fake pixel art with smooth cartoons. Keep smooth modern UI outside the scenic artwork exactly as specified.

## Pixel phong cảnh 16-bit

Authentic richly composed 16-BIT adventure-background PIXEL SCENES. Roughly 32–40 logical pixels across each property's picture, deliberately upscale 2–4x to make the square pixel clusters apparent. More layered depth than 8-bit: foreground flowers or small boats, middle-ground landmark, distant mountains/clouds; limited carefully chosen 24–32 color palette, discrete stepped shading, sparse controlled dithering. Bright jade foliage, aqua water, ochre architecture, coral lantern highlights, pale blue distant hills. Beautiful tiny pixel postcards with lively scenery while every edge remains pixel-grid stair-steps; absolutely no continuous gradients, smooth brushwork or vector antialiasing. Sophisticated yet visibly crunchy pixel craft. Maintain original smooth cream/navy/gold UI and ALL players bottom.

## Pixel isometric

Authentic ISOMETRIC PIXEL-ART DIORAMAS inside each location cell, like small hand-pixeled map tiles. Each landmark on a tiny diamond-shaped terrain base using precise 2:1 pixel staircase diagonals, about 28–36 logical pixels across, enlarged 3–4x with nearest-neighbor. Every visible edge is made of square pixels. Show tiny pixel buildings, blocky stepped hills, turquoise water tiles, 1–2 pixel boats, pixel-tree clusters. Distinct location-specific objects: miniature Hue gate on diamond plaza, Ha Long rocky pixel islands on water base, Nha Trang curved pixel shore, Sa Pa terrace steps, Hoi An tiny lantern street. About 20–28 saturated pastel colors with 3 discrete shade planes, no smooth 3D rendering, no clay, no voxel photo, no blur. Keep full board and UI top-down; ONLY tile artwork uses isometric view. Crisp smooth controls/text/player portraits remain as reference, all member cards below.
